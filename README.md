# 문자열 덧셈 계산기

## 프로그램 설명

### 파일 구조

```
/src
├─ App.js
├─ calculator.js
├─ constants.js
├─ index.js
├─ parser.js
└─ validator.js
```

### 기능 구현 목록 및 설명

- App.js : 입출력 및 에러 감지

  - [x] 문자열 입출력 받아서 trim() 하고 검증 단계로 넘김
  - [x] `결과 : $결과값` 형태로 출력
  - [x] 에러 감지 기능 → `[ERROR]` 출력

- calculator.js : 숫자 연산
  - [x] 숫자 배열을 인자로 받아서 reduce로 연산
- contants.js : 사용되는 상수 값 모음
  `DEFAULT_ERROR_MESSAGE` : 기본 에러 → [ERROR]
  `BLANK_INPUT_ERROR_MESSAGE` : 입력 값 없음 에러 → 0 출력
  `DEFAULT_DELIMITERS` : 기본 구분자 → `,;`
  `DELIMITER_REGEX` : 커스텀 구분자 추출 정규표현식 → `//[구분자]\n`
  `FRONT_PART_REGEX` : 커스텀 구분자의 앞 부분 → `//`
  `BACK_PART_REGEX` : 커스텀 구분자의 뒤 부분 → `\\n`
- index.js : 프로그램 시작점, App.js 실행

- parser.js : 문자열 계산 가능한 형태로 가공
  - [x] 입력 값 커스텀 구분자 확인
  - [x] 커스텀 구분자 았을 시 추출하기
    - [x] 한 번에 여러 구분자 들어오는 경우 정규표현식으로 추출
    - [x] 커스텀 구분자 형식 여러 번 반복되는 경우 파싱하여 추출
  - [x] 커스텀 구분자 아닐 시 기본 구분자로 파싱 진행
- validator.js : 입력값 유효 검사
  - [x] 입력 값 길이 확인 → 입력 값 공백일 시 throw ERROR
  - [x] 입력값 양수인 정수인지 확인
  - [x] 이외의 경우황 [ERROR] 발생

### 예외 처리

1. 일반적인 입력 값은 아니지만 정상적으로 처리 하는 경우
   - 입력 값이 없는 경우 : 0 출력
   - 커스텀 구분자 사이 문자 없는 경우 : `//\n`
   - 커스텀 구분자로 `/`가 들어 간 경우 : `///\n`
   - 커스텀 구분자 형식 하나에 여러 개 함께 있는 경우 : `//!@#\n`
     → 구분자 `, ; ! @ #`
   - 커스텀 구분자 형식 여러 개 있는 경우 : `//!\n//@\n`
     → 구분자 `, ; ! @`
   - 입력 값 사이에 공백 있는 경우 : `4 ; 5,2` 또는 `//h\\n4 ; 5 h2 ,1`
2. 에러로 처리하는 경우
   - 정해진 형식이 아닌 형태의 값을 입력 할 경우
   - 커스텀 구분자나 기본 구분자가 아닌 다른 구분자가 있는 경우 : `//d\\n2d3,8g7` → g는 등록되지 않은 구분자
   - 입력 값에 소수(decimal), 0 또는 음수가 있는 경우 : 문제의 조건이 `양수`로 제한 되어 있음
   - 커스텀 구분자로 `\`가 들어 온 경우 : 프로그램에서 백슬래쉬 처리를 하지 못하게 함
     - 추후에 가능하게 리팩토링 해볼 예정. 현재로써는 에러 처리됨

### 실행 시 명령어 유의점

1. 콘솔을 통해 기본 구분자를 사용하거나 커스텀 구분자를 설정하여 덧셈을 수행할 식을 작성합니다. 정해진 형식이 아닌 다른 문자를 입력한다면 에러가 발생합니다.

   ```jsx
   기본 구분자 : , ; // 입력 : 1;2,3 -> 숫자 1,2,3이 들어감

   커스텀 구분자 : //[구분자 입력]\n : //d\n4,6;2d8 -> 숫자 4,6,2,8이 들어감
   ```

1. 만약 입력 값이 올바르다면 입력 값들을 모두 더한 값을 출력 받을 수 있으며, 아닐 시 `[ERROR]` 가 출력됩니다. 아무 것도 입력하지 않으면 `0` 이 출력됩니다.
