# **javascript-calculator-precourse**

## 기능 목록

### 입력 - App.js: 입력값 받기

- [ ] 문자열 입출력 받아서 trim() 하고 검증 단계로 넘김

### 검증 - validator.js : 입력값 유효 검사

- [ ] 입력 값 길이 확인 → 출력 값 0
- [ ] 입력 값 커스텀 구분자 확인
  - [ ] 커스텀 구분자 맞을 시 정규 패턴식에 추가
  - [ ] 아닐 시 [ERROR] 발생
- [ ] 숫자 양수인지 확인
  - [ ] 음수 일 시 [ERROR] 발생

### 문자열 파싱 - parser.js : 문자열 자르기, 계산 가능한 형태로 가공

- [ ] 정규패턴식으로 처리 할 수 없는 기호 확인
  - [ ] 있을 시 [ERROR] 발생

### 연산 - calculation.js : 숫자 연산

- [ ] 숫자 배열을 인자로 받아서 덧셈 연산 후 값 출력

### 출력 - print.js : 결과 출력

- [ ] `결과 : $결과값` 형태로 출력

### 테스트

- [ ] 중간에 커스텀 구분자 / 기본 구분자 하나 빠진 경우
- [ ] 기본 구분자가 아닌 다른 기호로 구분자가 들어 온 경우
- [ ] 숫자가 아닌 문자가 들어간 경우
- [ ] 숫자가 아닌 기호가 들어간 경우
- [ ] 소수점이 들어 온 경우
- [ ] `0` 만 들어 온 경우
- [ ] 입력 사이에 `0` 이 들어 온 경우
