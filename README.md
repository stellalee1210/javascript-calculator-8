# **javascript-calculator-precourse**

## 기능 목록

### 입력 - App.js: 입력값 받기

- [x] 문자열 입출력 받아서 trim() 하고 검증 단계로 넘김

### 검증 - validator.js : **입력값 유효 검사,**

- [x] 입력 값 길이 확인 → 출력 값 0
- [x] 입력 값 커스텀 구분자 확인
  - [x] 아닐 시 [ERROR] 발생
- [x] 숫자 양수인지 확인
  - [x] 음수 일 시 [ERROR] 발생

### **문자열 파싱 - parser.js : 문자열 자르기, 계산 가능한 형태로 가공**

- [x] 커스텀 구분자 맞을 시 추출하기
  - [x] 커스텀 구분자 아닐 시 기본 구분자로 파싱 진행

### 연산 - calculation.js : 숫자 연산

- [x] 숫자 배열을 인자로 받아서 덧셈 연산 후 값 출력

### 출력 - print.js : 결과 출력

- [x] `결과 : $결과값` 형태로 출력

### 테스트

- [ ] 입력 값이 공백인 경우
- [ ] 입력값에 커스텀구분자 없이 기본 구분자가 아닌 다른 기호로 구분자가 들어 있는 경우
- [ ] 입력 값으로 소수점이 들어 온 경우
- [ ] 올바른 입력 값 사이에 공백이 있는 경우
  - [ ] 기본 구분자
  - [ ] 커스텀 구분자
- [ ] 커스텀 구분자로 아무 기호도 안 들어 간 경우
